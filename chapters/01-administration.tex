\chapter{Administration}
\label{ch:administration}

This chapter contains all of the initial administration processes I needed to do, and the order in which I did them.

\section{Registering with Learning@Wales}

\begin{enumerate}
    \item Go to
    \href{https://learning.nhs.wales/}{\texttt{learning.nhs.wales}}.

    \item Select \term{Learning@Wales}.

    \item Select the button right below the text that says

    \begin{quote}
        \enquote{Please click the button below to register for an
        account if you are unable to self-register.}
    \end{quote}
\end{enumerate}

\section{Required training}

Complete the following training modules:

\begin{itemize}
    \item Information Governance
    \item Fire Safety
    \item Infection Control
    \item Health \& Safety
    \item Treat Me Fairly
    \item Safeguarding People
    \item Violence Against Women
    \item Violence and Aggression
    \item Manual Handling
    \item ANTT 
\end{itemize}
